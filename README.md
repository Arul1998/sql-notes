## Repository Structure

- [`lessons/`](lessons/) – SQL explanations, examples, and exercises
- [`answers/`](answers/) – Answers for each exercise

Every lesson and answer has its own Markdown file, organized into matching numbered topic folders.

## Topics Covered

### Lessons 1–100

- `SELECT`, `WHERE`, and `ORDER BY`
- `DISTINCT` and `TOP`
- `AND`, `OR`, `BETWEEN`, and `IN`
- `LIKE` and wildcards
- `NULL` values
- Aggregate functions, `GROUP BY`, and `HAVING`
- SQL joins
- `INSERT`, `UPDATE`, and `DELETE`
- Conditional expressions with `CASE`, `IIF`, and `CHOOSE`
- NULL handling with `ISNULL`, `COALESCE`, and `NULLIF`
- String functions such as `CONCAT`, `LEN`, `TRIM`, and `SUBSTRING`
- Formatting and rounding with `FORMAT`, `ROUND`, `CEILING`, and `FLOOR`
- Mathematical functions such as `ABS`, `POWER`, and `SQRT`
- Date and time functions such as `GETDATE`, `DATEADD`, `DATEDIFF`, `DATEPART`, and `EOMONTH`
- Data type conversion with `CAST`, `CONVERT`, `TRY_CAST`, and `TRY_CONVERT`
- Data validation with `ISDATE` and `ISNUMERIC`

## How to Learn

1. Open a file from the [`lessons`](lessons/) folder.
2. Read the explanation and example.
3. Complete the exercise before viewing the answer.
4. Check the matching file in the [`answers`](answers/) folder.
5. Correct any mistakes and practise again.
