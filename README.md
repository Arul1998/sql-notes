# SQL Server Learning Notes

Simple SQL Server lessons, examples, exercises, and answers for beginners.

## Progress

- ✅ Lessons 1–50 completed
- ⏳ Lessons 51–75 in progress
- 📅 Lessons 76–100 planned

## Repository Structure

- `lessons` – SQL explanations, examples, and exercises
- `answers` – Answers for each exercise

Every lesson and answer has its own Markdown file.

## Topics Covered

- `SELECT`, `WHERE`, and `ORDER BY`
- `DISTINCT` and `TOP`
- `AND`, `OR`, `BETWEEN`, and `IN`
- `LIKE` and wildcards
- `NULL` values
- Aggregate functions
- `GROUP BY` and `HAVING`
- SQL joins
- `INSERT`, `UPDATE`, and `DELETE`

All examples use Microsoft SQL Server and T-SQL.

## How to Learn

1. Open a file from the `lessons` folder.
2. Read the example.
3. Complete the exercise.
4. Check the matching file in the `answers` folder.
5. Correct any mistakes and practise again.
